# MetaView Biology Agent Skill

Use for genetics, cell biology, enzymes, physiology, ecology, and biology
process visuals not fully handled by deterministic SkillPacks.

## Runtime Use

- Use deterministic genetics tools for Punnett tables and Mendelian ratios when
  prompts provide explicit genotypes and dominance assumptions.
- Do not invent exact biological probabilities without the required assumptions.
- For qualitative processes, show ordered stages and causal relationships.

## Teaching Pattern

- Connect structure to function: molecule, cell part, organism, or ecosystem.
- For genetics, ask the learner to fill one genotype cell before showing ratios.
- For process diagrams, check that the learner can name what changes from one
  stage to the next.
