# ADR: 课包优先（Coursepack-First）产品战略

Status: accepted（决策人 jry21223，2026-08-24）

本 ADR 取代 #246 中尚未落地的 Core Rescue 范围冻结 ADR：范围冻结仍然执行，
但冻结的锚点从"救援开放式生成"改为"课包优先"。任何开发 Agent 在判断一个
需求是否属于当前阶段时，以本文件为准。

## Context

截至 2026-08-24 的事实：

- 开放式生成链路未形成稳定闭环：`GENERATION_DISABLED` 全局开关自 2026-08-01
  起误开两周无人发现（7e2c897）；二分查找确定性路由三次尝试当日全部
  revert（f0fb818 / 1fb9b93 / abe01e7），最终以打开静态模板收场（7aa7c6a）。
- 巨型 PR #161（+6035 行）挂三周 draft 后未合并关闭；重切片 #257–#261 至今
  只落地一片（#262）。
- 四条战线并行（#160 harness、#171–#192 视觉规范、#209–#221 Wayfinder、
  #246–#255 Core Rescue），73 个 open issue，零条收敛。
- 项目为单人 + Agent 开发。约束不是产码速度，是 owner 的验证带宽。
- 与此同时，真正稳定可用的资产是：人工校验的互动课包（16 个正式模板，
  含圆锥曲线 Gold Pack）、共享 PlaybookPlayer、参数交互、Code Sync、
  Follow-up 与视频导出链路。

## Decision

1. **产品定位**：MetaView 对外是"可交互学科课包"产品。卖的是可播放、
   可调参、可追问、可布置的理解过程，不是静态资料，也不是"任意输入
   生成讲解"。对外承诺从生成能力改为精选单元的深度与正确性。
2. **首发垂直**：高中数学 · 圆锥曲线，P0 为"椭圆的定义"（沿用 #210 的
   P0 锁定与 #222 的人教 A 版教材边界核验）。首个买单画像是**个体高中
   数学教师**；学生/家长为第二画像。
3. **生成链路降级为内部工具**：生成只用于加速课包制作，产出必须经人工
   校验后以静态课包发布。`/create` 开放生成入口保留但标记为实验能力，
   不进入任何对外宣传与承诺。
4. **学校合作路径**：个体教师真实使用 → 教研组/备课组试点 → 学校。
   在获得 10 名外部复用用户之前，不为学校采购构建任何东西。
5. **分发结构**：视频导出产物作为免费引流内容（短视频平台），互动课包
   作为付费产品（锁定在播放器内，天然抗盗版）。

## Frozen（解冻条件达成前一律不做）

- 新学科 SkillPack 与学科扩张
- Agent harness 收敛与迁移切片（#160、#257–#261）
- 视觉规范迁移批次（#171–#189）
- Core Rescue 生成救援（#246–#255）
- Observability 扩展（#190–#192）
- 支付/充值新功能、ops edition 新能力、SEO/GEO、MCP server、
  PPT deck（PR #224）、Landing 视觉打磨
- 已存在的上述代码不删除、不投入。

## Unlock conditions（解冻条件）

- **扩张解冻**（新单元/新学科/商业化基建）：≥10 名外部用户中至少 3 人
  第二次主动使用，或出现第一笔真实付费。
- **生成对外解冻**：内部制作课包时，某一 archetype 连续 20 次生成通过
  人工校验且无需修改，届时重新评估开放生成入口。

## Working agreements（对 Agent 开发模式）

- 单条 Agent 战线：同一时刻只允许一个进行中的 Agent 任务。
- PR 上限约 400 行，owner 必须能当天验证完；每个 issue 附一条可执行的
  验证命令与期望输出，验收只看命令结果。
- 不可验证的产出视为零产出（教训：PR #161）。

## 30-day plan

- **W1**：执行 issue bankruptcy 与冻结；确定椭圆课包 v1 内容清单与定价
  假设；README / Landing 重定位为课包目录。
- **W2**：椭圆课包 v1 达到"教师可直接在课堂使用"状态；产出 1 页销售
  说明与 3 条导出短视频素材。
- **W3–W4**：5 名真实教师/学生实际使用并现场观察；每周只修真实用户
  遇到的问题；记录付费意愿信号。
- **Day 30 Go/No-Go**（兑现 #221）：无任何外部人第二次使用 → 重审方向
  本身，而不是追加工程。

## 唯一 KPI

外部复用用户数：一个真实的人第二次主动打开课包。该数字 < 10 之前，
一切内部工程指标（覆盖率、benchmark 分数、gate 通过率）不作为进度依据。

## Consequences

- 放弃短期"任意题目生成"的对外故事。与 chat 类 AI 的差异化改为三点
  结构性优势：课程对齐、人工背书的正确性、可交互可布置。
- 广度与随问随答让给 chat 类产品，不在该前线竞争。
- ops / 支付 / agent 基建转入冷冻而非删除，保留未来选项。
