# 高中化学课程包 · `chemistry_scene`

Status: Active（本地实现完成，未提交；等待 owner 审阅）

本文是化学板块重做的规格与记录：现状审计、参考来源、视觉语言、五个正式案例、架构改动、测试接缝、假设、owner 的决定与仍待决定的问题。进度日志见 [worklogs/chemistry-rework.md](./worklogs/chemistry-rework.md)。

## 问题（从使用者角度）

`/templates` 的化学分区此前被隐藏：唯一的正式案例 `redox-electron` 只有六张“卡片 + 箭头”的示意，没有粒子、没有装置、没有动画；中和滴定只是“制作中”占位。AI 生成的化学运行（如 2H₂ + O₂ → 2H₂O、Zn/Cu 置换）也用同样的渲染器，画面同样单薄。老师看到的是“一行方程式配几张框”，而不是能讲清楚宏观—微观—符号三重表征的过程动画。

## 方案（从使用者角度）

- 一个新的快照类型 `chemistry_scene`：同一个 16:9 舞台上并排放多个面板——伪 3D 球棍/比例模型、粒子放大图、原电池与滴定装置、曲线图、能量–反应进程图、方程卡片——面板之间逐步联动，键的断裂与形成、离子迁移、电子流动都有动画。
- 五个公开正式案例，按课本顺序放进目录里新的“化学”分区，取代 `redox-electron` 与中和占位。
- 每个案例 8–9 步、可调参数只放在能教东西的地方、每步三问（看什么 / 为什么 / 怎样自己检查）、旁白可朗读、线描缩略图与真实帧海报。
- 所有数值由确定性领域模型现算，并有独立数值来源的测试；每一步的原子守恒、标签不压形状、不出舞台都有测试兜底。

## 用户故事

1. 作为高中化学老师，我想在课上直接打开一个正式案例讲原电池，这样不用自己画盐桥和离子迁移。
2. 作为老师，我想同一画面里同时看到装置、放大的电极表面和电极反应式，这样能把宏观现象、微观粒子和符号对应起来讲。
3. 作为学生，我想看到锌原子离开晶格变成 Zn²⁺、铜离子在铜片上变成铜原子，这样“失电子被氧化”不再只是一句话。
4. 作为学生，我想看到没有盐桥时电流计不动、接上盐桥后才偏转，这样理解盐桥为什么必需。
5. 作为学生，我想拖动“通过电子”的滑杆，看两极质量按比例变化，这样学会用电子守恒计算。
6. 作为老师，我想把负极换成铁，看电压和离子（Fe²⁺ 而不是 Fe³⁺）一起变，这样纠正常见错误。
7. 作为学生，我想看到滴定曲线、滴定管刻度、锥形瓶颜色和放大的离子随每一滴同步变化，这样理解 pH 突变。
8. 作为学生，我想看到 19.98 mL 与 20.02 mL 两点的读数，这样明白“一滴之差”指的是什么。
9. 作为老师，我想切换浓度和指示剂，让学生自己发现稀溶液中甲基橙误差变大，这样指示剂选择有依据。
10. 作为学生，我想在同一条时间轴上看到加 N₂、压缩、升温三次扰动，这样把勒夏特列原理看成一条统一的规律。
11. 作为学生，我想每次扰动都有 Q 与 K 的数值对比，这样能自己判断平衡移动方向。
12. 作为学生，我想看到反应容器里的分子数随平衡移动而变化，而原子总数不变，这样理解“平衡移动”是真实的粒子变化。
13. 作为学生，我想看到 ¹⁸O 标记在整个机理中一直留在乙醇这一侧、最后进入酯，这样“酸脱羟基醇脱氢”有了证据链。
14. 作为学生，我想看到每一步机理中哪根键断开、哪根键形成、弯箭头指向哪里，这样能读懂有机反应机理。
15. 作为老师，我想在球棍模型和比例模型之间切换，这样顺带复习两种分子模型。
16. 作为学生，我想看到取向不对的碰撞弹开、取向合适的碰撞经过过渡态，这样理解有效碰撞的两个条件。
17. 作为学生，我想在能量图上看到活化能和反应热，并看到催化剂把能垒降低但不改变反应热，这样理解催化剂为什么不移动平衡。
18. 作为学生，我想调温度看活化分子比例和速率倍数怎样变化，这样知道温度影响为什么这么大。
19. 作为学生，我想每一步都能点“看什么 / 为什么 / 怎样检查”三个问题并得到具体的答案，这样能自学。
20. 作为视障或使用语音的学生，我想旁白里没有 TTS 读不出的符号，这样听到的讲解是完整的。
21. 作为运营，我想这些案例在浏览器与导出视频中完全一致，并且不调用 API、不扣额度，这样可以放心公开。
22. 作为维护者，我想每一步的原子守恒、标签不遮挡都有自动测试，这样以后改动不会悄悄破坏画面或化学事实。

**可用的部分**

- `features/playbook/engine/kits/chemistry/chemistryLayouts.ts` 的 `compileMolecule2DLayout` / `compileReactionLayout` 能把结构化原子、键、参与物编译成快照，并有 SMILES → 预置结构的解析（`moleculePresetResolver.ts`），API 侧也有对应的 `chemistry_layout_compiler.py` 与 RDKit 编译器；这条路径服务 AI 生成，保留不动。
- `chemistry_stoichiometry` SkillPack（方程配平、摩尔质量、限量反应物、浓度）确定性、有测试，输出表格/公式/柱图，不依赖化学渲染器。
- `data-semantic-role` 等语义标记齐全，便于质量门与测试检查。

**薄弱之处**

- 画布是 `viewBox 0 0 100 100` 的正方形，放进约 2.2 : 1 的舞台后只用了中间一半宽度，两侧大片空白（与线上 `dna-replication` 末步同一问题）。
- 颜色写死（`#fff8e7`、`#d7a83f`、`#111827`、`#f8fbff` …），不走 DESIGN.md 语义 token；深色主题只把底换成藏青色，参与物卡片仍是浅色，和舞台的深绿黑底打架（`ReactionSceneRenderer.tsx`、`Molecule2DSceneRenderer.tsx`）。
- 参与物卡片固定 20 宽、按输入坐标摆放，间距小于 20 时直接重叠：`redox-electron` 第 2–6 步 `Zn²⁺` 与 `Cu` 卡片相互遮挡，“锌离子，+2价”被截断，“发生氧化还原”被生成物卡片盖住，两个氧化数 callout 叠在一起（见审计截图 step-02/05）。
- callout 位置用固定偏移，没有碰撞检测；公式标签把 `\rightarrow` 替换成 `->`、下标保留下划线（`H_2O`）。
- 没有任何动画：`progress`、`frame` 未被使用；没有微观粒子、没有装置、没有能量图。
- 原子是扁平圆，半径按元素写死（H 7、O 9.5、其余 8.2），不是 CPK 配色，没有深度；分子标签默认英文（“bent geometry”“balanced atoms”）。
- `redox-electron` 案例：6 步、无参数、每步 Follow-up 的“检查”答案全部相同。
- 工具缺陷：`apps/web/scripts/render-template-shots.mjs --themes light,dark` 渲出的 dark 图与 light 图逐字节相同（composition 只按第一个主题选了一次），深色从未被真正审过——本次已修。

## 视觉语言

- **三重表征同屏**：宏观（装置、溶液颜色、仪表读数）、微观（粒子放大图、分子模型）、符号（方程卡片、曲线、能量图）在同一步里同时出现、同时变化。
- **舞台**：`chemistry_scene` 固定 1000 × 456 单位（与数学图同比例，约 2.19 : 1），面板用满宽度；顶部一行放步骤标题与方程式胶囊，底部一行放“看哪里”的说明。
- **颜色**：结构与强调全部走 `var(--ink*)`、`var(--line*)`、`var(--canvas-primary|secondary|focus)`，回退值来自 `THEME_PALETTE`，Remotion 导出与浏览器一致；元素颜色是 CPK/Jmol 惯例的降饱和版本（`kits/chemistry/elements.ts`），溶液与指示剂色（`chemPalette.ts` 的 `TINT_HEX`）作为有化学含义的命名常量留在渲染器边界（DESIGN.md §16.1）。
- **原子**：径向渐变球体（左上高光、右下阴影、深处向背景色雾化 32%），球上写元素符号，同位素写成 ¹⁸O，形式电荷用 ⊕/⊖ 徽标；球棍模型的键是两色半截棍，按原子半径收进球内。
- **粒子**：介于球棍与比例模型之间的紧凑球（氢也有可读尺寸），旁观离子（SO₄²⁻、Na⁺、Cl⁻）降为 45% 不透明度，主角带聚焦圈。
- **标签**：所有文字要么在固定区域（有测试证明不压形状），要么交给避障布局——候选位置按“首选方向 → 其余方向 → 斜向”、再沿边滑动、再加大距离逐一尝试，找不到干净位置就报告重叠，由测试失败而不是悄悄遮挡。曲线末端的系列标签先按线的上下顺序等距排开、限制在绘图区内（不落到横轴下方被误读成刻度），再交给避障布局；callout 的引线从目标的边缘而不是圆心出发，不盖住它所指的粒子。公式标记无法排版的写法（如上标里再套下标）会被布局检查报为 `raw-markup`。
- **箭头**：机理步骤里每一对移动的电子各画一个弯箭头（从电子来源指向去处，下一步才发生的事先预告）；原电池的离子迁移画成虚线轨迹 + 箭头，离子沿轨迹移动，暂停帧与海报上也看得出方向；电子流在导线上方标 e⁻ 方向，并有沿导线移动的电子。
- **动效**：换步时同一面板内的原子/粒子在 42 帧内滑到新位置（固定入场预算，旁白长短不影响断键速度）；标签与弯箭头在几何稳定后淡入；粒子热运动是按 id 生成的确定性李萨如摆动，暂停帧、导出帧、测试看到的一模一样。

## 架构改动

- **新快照类型 `chemistry_scene`**（web `kits/chemistry/sceneTypes.ts`，经 `types.ts` 并入 `SnapshotKind` / `AnySnapshot`；渲染器登记在 `renderers/registry.ts`；API `app/domain/models/playbook.py` 的 `ChemistrySceneSnapshot` 只校验面板信封（`type`、`id`、`rect`），面板主体 `extra="allow"` 原样保留；agent `SUPPORTED_FRONTEND_SNAPSHOT_KINDS` 同步）。`test_snapshot_contract_consistency.py` 保证三端种类一致。目前只有正式案例产出这种快照，生成管线的 prompt 没有提到它。
- **纯函数内核**（`features/playbook/engine/kits/chemistry/`）：`chemMarkup`（`_`/`^` 公式标记 → tspan，Unicode 互转，确定性宽度估计）、`elements`、`chemSpecies`（粒子物种库）、`projection`、`labelLayout`、`atomLedger`、`equationBalance`（按公式标记解析方程式并检查原子、电荷配平，含同位素）、`transitions`、`geometry/*`（每类面板的形状、固定文字、锚点、弹性标签）、`sceneLayout`（整舞台布局 + `chemistryLayoutProblems`）。渲染器（`renderers/chemistry/*`）只负责画布局给出的东西和按帧插值。
- **案例脚手架**：`gold-templates/chemistry/chemistryCase.ts` 让每个案例只写一个 `build(params)`，一次产出步骤与三问；manifest、脚本、Follow-up 都从它派生。领域模型各自成文件：`titrationDomain`、`haberDomain`、`collisionDomain`、`galvanicDomain`、`esterMechanism`；数字格式（`chemFormat`）统一屏幕、标记与朗读三种写法。
- **目录**：`templates.ts` 新增化学分区；`redox-electron` 的 manifest、线描与海报删除（其内容被 `galvanic-cell` 完整覆盖）；`crossSubjectGoldTemplates` 不再含化学科目。旧链接由 `templates.ts` 导出的 `RETIRED_TEMPLATE_REDIRECTS` 登记，`TemplatePreviewPage` 命中即 `replace` 跳转到替代案例（`TemplatePreviewPage.test.tsx` 保证退役 id 不在目录里、目标在目录里且可播放）。
- **旧渲染器顺带升级**（AI 生成路径受益；只有既有单元/fixture 测试覆盖，没有用真实 AI 运行验证）：`Molecule2DSceneRenderer` 与 `ReactionSceneRenderer` 改用 178 × 100 宽画布、语义 token、CPK 球体、公式转 Unicode；参与物横向按宽画布拉开，修掉卡片互相覆盖。`CoreCalloutLabel` 增加可选 `fill`（默认仍为白色，其他渲染器不变）。
- **SkillPack**：没有新增确定性 skill，`build_default_skill_registry()` 未改（见“不在范围内”）。
- **依赖**：没有新增依赖。伪 3D 用 SVG 手算投影即可满足确定性渲染，没有必要引入 Three.js 一类库（Remotion 下还要处理 WebGL 截帧的不确定性）。

## 决定（2026-09-24）

owner 审阅后把前四个待决问题交给协调人决定：

1. **旧链接重定向。** `/templates/redox-electron` 用 `replace` 跳转到 `/templates/galvanic-cell`，分享出去或收藏的旧链接继续可用。退役 id 登记在 `templates.ts` 的 `RETIRED_TEMPLATE_REDIRECTS`；`TemplatePreviewPage.test.tsx` 先红后绿，验证跳转本身，以及“退役 id 不在目录、目标在目录且有可播放案例”。
2. **HI 分解的活化能保持 184 kJ/mol，Pt 表面 59 kJ/mol。** 两个数出自 Atkins 物理化学的催化活化能表，两者成对使用才能保证“催化剂降低多少”的对比来自同一来源；其他教辅里的 186、209.5 kJ/mol 不混用。代码不改。
3. **甲基橙终点保持“滴到刚变黄（pH 4.4）”。** 这是与 0.1% 误差推理自洽的终点：pH 3.1 刚变橙时离恰好中和还差约 1.6%（0.1 mol/L）。习题答案常写“由红色变为橙色，且半分钟内不变色”（例如 [菁优网的一道滴定题](https://www.jyeoo.com/shiti/210dd93e-1522-415c-b556-725af1a30f12/)），所以选用甲基橙时，第 6 步“怎样判断终点已经到达？”的答案补一句说明两者的关系：“由红色变为橙色”指颜色开始变化的时刻；按误差计算，要滴到刚变黄（pH 4.4）才在 0.1% 以内。0.01 mol/L 时即使变黄误差也超过 0.1%，答案按实情说明。追问答案只以文字显示，没有朗读路径。
4. **本次不生成旁白音频。** 目前只有 5 个生态案例带录好的旁白（`apps/web/public/template-narration/`），这台机器上也没有 `METAVIEW_TTS_*` 配置；化学案例与其余 24 个正式案例一样只显示字幕。以后需要配音时，按生态案例的流程另行生成。
